A Service is an [Endpoint](/docs/program/endpoints) other Programs reach by a
name, without seeing your Program or its Processes. It is not a separate thing
that runs: it is an Endpoint holding a Service name.

## The name

A Service name, such as `file-picker-v1`, is one word or several joined by
hyphens, in lowercase letters and digits. It is the contract: whoever holds it
answers what it promises. A contract that changes takes a new name, so the
version goes in the name.

A name is public across the System and held by one Endpoint at a time, a Server
or a Client. It is apart from the Process name, which stays local to its
Program: a Process named `picker` can hold `file-picker-v1`.

## Offer one

```ts
await program.createProcess({ name: "picker", server: { service: "file-picker-v1" } })
```

A Program can also declare the name in its
[configuration](/docs/sdks/core#program-configuration), and every launch takes
it unless it says otherwise. `service: false` in a launch offers none, whatever
is declared. The Service is available while its Endpoint runs and is ready.

Starting an Endpoint with a name another Endpoint holds takes the name: the
holder's whole Process ends first.

## Reach one

```ts
const picker = system.service({ name: "file-picker-v1", endpoint: "server" })

await picker.waitReady()
const chosen = await picker.ask("open", { types: ["text/plain"] })
picker.subscribe("changed", change => {})
```

The handle is returned at once and contacts nobody: whether something holds the
name, and whether you may reach it, is checked when you use it. The same name
reaches its next holder.

| `endpoint` | Reaches |
| --- | --- |
| `"server"` | A Server holding the name. Only a Server answers questions. |
| `"client"` | A Client holding the name. |
| Left out | Whichever holds it, for what both share: publishing, subscribing, waiting. |

## Who holds them

The [Process](/docs/program/processes) list shows which Endpoint holds each
name. A Service never tells its callers who provides it.

## Permissions

Reaching a Service needs the `consumeServices`
[permission](/docs/system/permissions) for its name. Offering one needs
`provideServices` for its name, checked against whoever starts the Endpoint:
the name a launch passes, or the one the Program declares.

## From the terminal

```sh
phresh service ask --name file-picker-v1 --event open --payload '{}'
phresh service wait-ready --name file-picker-v1 --endpoint server
phresh process list   # which Process holds each name
```
