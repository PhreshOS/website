`context` is how code running inside an Endpoint talks about itself. It tells
the code which Program and Process it belongs to, gives it the options it was
launched with, receives the messages sent to it, and, in a Server, answers
questions.

```ts
import { context } from "@phreshos/server"   // in a Server
import { context } from "@phreshos/client"   // in a Client

const document = await context.options("document")
```

Node scripts and the CLI do not run inside an Endpoint, so they have `system`
but no `context`.

## Context and Endpoint handles

An [Endpoint handle](/docs/runtime/endpoints), such as `process.server`, addresses
a role from the outside and stays valid across restarts. `context` is the
current run seen from the inside.

Everything you register through `context`, such as subscriptions and answers,
belongs to the current run and ends when it stops. A restarted Endpoint starts
with a fresh `context` and registers again.

## Know where you are

```ts
const program = await context.program()   // the Program
const process = await context.process()   // the Process
const name = await context.name()         // the Process name, or null
const parent = await context.parent()     // the Process that created yours, or null
await context.isService()                  // whether this run is a Service
```

## Read launch options

`options()` returns the options given when the Process was created. Both
Endpoints of a Process see the same values:

```ts
await context.options()              // { document: "notes/today.md" }
await context.options("document")    // "notes/today.md"
```

See [Pass options](/docs/runtime/processes#pass-options).

## Receive messages

`context` receives every message sent to this Endpoint, from its paired
Endpoint, from other Programs, or through its Service. Each message says who
sent it:

```ts
context.subscribe("document.changed", ({ from, payload }) => {
  console.log(from, payload)
})
```

`from` is the sending Endpoint, or `null` when you are not allowed to see it.

`context.publish()` sends a message from this Endpoint without a destination,
to anyone observing it. See [Communication](/docs/runtime/communication).

## Answer questions (Server)

A Server registers one handler per question:

```ts
import { context } from "@phreshos/server"

const cleanup = context.answer("notes.list", async ({ from, payload }) => {
  return await loadNotes()
})
```

Whatever the handler returns becomes the answer; if it throws, the question
rejects with the error's message. `answer()` returns a function that removes
the handler.

A question name has one handler at a time, so every question has exactly one
answer. Registering a second handler for the same name throws.

## Reach the other Endpoint

Each Endpoint's `context` holds a handle to its partner in the same Process:

```ts
// In a Client
const notes = await context.server.ask("notes.list")

// In a Server
await context.client.start()
await context.client.window.setTitle("Notes")
```

## Control the Window (Client)

A Client's `context` gives it two views of its Window:

- `context.window` is the Window itself, shared by every Desktop that shows
  it: its title, size, position, and state.
- `context.presentation` is how this Desktop draws it, such as its surface and
  whether it accepts input.

```ts
await context.window.setTitle("Notes")
await context.window.resize({ width: 900, height: 640 })
```

See [Desktop](/docs/system/desktop) for both.

## Stop this run

`context.stop()` stops the Endpoint that is running this code and releases
everything its run registered. Like [`stop()`](/docs/runtime/endpoints#start-and-stop)
on a handle, it cannot stop the last running Endpoint of a Process.

## Permissions

`context.permissions` reads the Program's effective permissions and can ask
the owner to grant more. See [Permissions](/docs/system/security/permissions).

## Reference

| Member | Available in | Result |
| --- | --- | --- |
| `program()`, `process()`, `name()`, `parent()` | Both | Where this run belongs |
| `options(name?)` | Both | Launch options |
| `isService()` | Both | Whether this run is a Service |
| `subscribe`, `wait`, `events` | Both | Messages sent to this Endpoint |
| `publish(event, payload?)` | Both | A message from this Endpoint |
| `permissions` | Both | Effective permissions and requests |
| `stop()` | Both | Stops this run |
| `server` | Client | The paired Server |
| `window`, `presentation` | Client | The Window and how this Desktop shows it |
| `client` | Server | The paired Client |
| `answer(event, handler)` | Server | Answers a question; returns a cleanup |
