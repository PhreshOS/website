Each Desktop has its own preferences, kept in its browser:

| Preference | Chosen | By default |
| --- | --- | --- |
| `theme` | `"light"`, `"dark"`, or `"browser"` | `"browser"` |
| `animations` | `true`, `false`, or `"browser"` | `"browser"` |
| `scale` | `0.5` to `2` | `1` |

`"browser"` follows the browser: its light or dark mode, and whether it asks
for reduced motion. So there are two readings: what was chosen, and what the
Desktop uses now. Only the Desktop knows its browser, so it resolves them.

```ts
await desktop.preferences.snapshot()   // chosen: { theme: "browser", animations: true, scale: 1 }
await desktop.preferences.resolve()    // used now: { theme: "dark", animations: true, scale: 1 }

desktop.preferences.subscribe("change", preferences => {})       // a choice changed
desktop.preferences.subscribe("changeResolved", resolved => {})  // what is used changed
```

A Program draws with what is used now. Only a place that lets the owner
choose, such as Settings, needs what was chosen.

Reading them is always allowed. Changing them needs the `desktopPreferences`
[permission](/docs/system/permissions):

```ts
await desktop.preferences.update({ theme: "dark", scale: 1.25 })
await desktop.preferences.update({ theme: "browser", animations: "browser" })
```

The scale is always a number, from 0.5 to 2; 1 is its normal size.

Changing the scale changes the size of the view a Client sees.

Preferences choose between light and dark. What light and dark look like is
the System's [Appearance](/docs/system/appearance), the same on every Desktop.

## The Connection

`desktop.connection()` returns the browser Connection showing this Desktop, and
through it the Session signed in. It needs the `desktopConnection` or the
`authentication` permission. See [Authentication](/docs/system/authentication).

```ts
const connection = await desktop.connection()
await connection.session()
```

## From the terminal

Preferences belong to the browser, so the terminal has none. It sees the
Connections:

```sh
phresh connection list
```
