<Steps>

<Step>

### Install PhreshOS

You need Node.js `24.15.0` or newer.

<Tabs items={["npm", "pnpm", "Bun", "Yarn Classic"]} groupId="package-manager" persist>
  <Tab value="npm">
    ```sh
    npm install --global @phreshos/cli
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Bun">
    ```sh
    bun add --global @phreshos/cli
    ```
  </Tab>
  <Tab value="Yarn Classic">
    ```sh
    yarn global add @phreshos/cli
    ```
  </Tab>
</Tabs>

```sh
phresh system install
```

This installs the System, starts it, and prints the Desktop address.

</Step>

<Step>

### Open the Desktop

Open the printed address in your browser, usually `http://localhost:4300`,
and create your owner account.

</Step>

<Step>

### Create a Program

```sh
phresh create my-program
```

The folder name becomes the Program's identity. Answer the remaining
questions, or press Enter to accept the defaults.

</Step>

<Step>

### Run it

```sh
cd my-program
phresh dev
```

Your Program's Window opens in the Desktop. Press `Ctrl+C` in the terminal to
stop it.

</Step>

</Steps>
