`phresh create` gives you a working Program: a counter whose value lives in a
Server and is shown by a Client. This page walks through it, adds a feature,
and installs the result.

It assumes you finished the [Quick start](/docs) and your Program runs with
`phresh dev`.

A Program has two sides, called [Endpoints](/docs/runtime/endpoints):

- the **Server** (`server/`) runs on the machine where PhreshOS is installed.
  It does not depend on a browser;
- the **Client** (`client/`) is the interface, shown in a Desktop Window. It
  is an ordinary web page, built here with React and Vite.

`phresh.config.ts` tells PhreshOS what the Program is called and where each
side lives:

```ts title="phresh.config.ts"
export default defineConfig({
  identity: "my-program",
  name: "My Program",
  server: {
    location: "dist/server",
    worker: "main.js",
    devCommand: "vite-node server/main.ts",
  },
  client: {
    location: "dist/client",
    title: "My Program",
    size: { width: 600, height: 500 },
    devCommand: "vite --config vite.client.ts",
  },
})
```

`phresh dev` runs the `devCommand`s. Installing uses the built files in each
`location`. Every field is described in
[Program configuration](/docs/sdks/core/program-configuration).

## How the two sides talk

The Server holds the count. It answers one question and reacts to one
message:

```ts title="server/main.ts"
import { context } from "@phreshos/server"

let count = 0

// Answer the question "read" with the current count
context.answer("read", () => count)

// When someone sends "increment", count and announce the new value
context.subscribe("increment", () => {
  count += 1
  context.publish("changed", count)
})
```

The Client asks for the count once, then listens for changes:

```tsx title="client/app.tsx"
import { context } from "@phreshos/client"
import { useSubscribe } from "@phreshos/react"
import { useEffect, useState } from "react"

export default function App() {
  const [count, setCount] = useState<number>()

  // Follow every "changed" the Server announces
  useSubscribe(context.server, "changed", setCount)

  // Ask for the current value once
  useEffect(() => {
    context.server.ask<number>("read").then(setCount)
  }, [])

  return (
    <button onClick={() => context.server.publish("increment")}>
      Count is {count ?? "…"}
    </button>
  )
}
```

These are the two ways Endpoints communicate:

| | Use it when | Here |
| --- | --- | --- |
| **Ask** | You need an answer | The Client asks `read` and gets the count |
| **Publish** | You announce something, with no reply | The Client sends `increment`; the Server announces `changed` |

Because the count lives in the Server, every Desktop showing this Process
sees the same value, and reloading the Window does not reset it.

See [Communication](/docs/runtime/communication) for everything these operations
can do.

## Add a feature

Add a reset. In the Server, answer a new question:

```ts title="server/main.ts"
context.answer("reset", () => {
  count = 0
  context.publish("changed", count)
})
```

In the Client, add a button that asks it:

```tsx title="client/app.tsx"
<button onClick={() => context.server.ask("reset")}>Reset</button>
```

The Client reloads as soon as you save. Server changes take effect the next
time it starts, so stop `phresh dev` with `Ctrl+C` and run it again.

Reset is a question rather than a message so the Client knows when it has
happened, and would see an error if it failed.

## Install it

`phresh dev` runs your Program only while the command runs. Installing copies
a built version into the System, so it stays available after you close the
terminal and after the System restarts:

```sh
phresh install --run
```

This runs the project's build, installs the result, and `--run` opens it
right away. From now on you can open it from the Desktop like any other
Program.

To remove it again:

```sh
phresh uninstall
```
