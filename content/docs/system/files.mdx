A `Storage` is a folder and a `StorageFile` is a file. The same operations
reach three places:

| Place | Is | Permission |
| --- | --- | --- |
| `program.data` | Your Program's files to keep | None |
| `program.cache` | Your Program's files that can be made again, and may be deleted | None |
| `system.storage` | The files on the machine, from the home folder of the user running PhreshOS | `storage` |

```ts
const program = await context.program()

await program.data.file("settings.json").write({ theme: "dark" })
await system.storage.navigate("Documents").list()
```

Small values and structured data have their own places: the store and the
database, in [Data](/docs/system/data).

## Choose a folder or a file

Choosing touches nothing on the disk; only an operation does:

```ts
const reports = program.data.navigate("reports", "2026")
const today = reports.file("today.json")
const index = program.cache.file("search", "index.bin")

await today.name()   // "today.json"
await today.path()   // its absolute path
```

## Files

```ts
await today.write({ done: true })              // replaces the file at once
await today.append("\nmore")                   // adds to the end
await today.json()                             // reads it as JSON
await today.text()                             // as text
await today.bytes({ offset: 0, length: 64 })   // some of its bytes
await today.stream()                           // as a stream
await today.stat()                             // { size, modifiedAt }, or null
await today.delete()
```

`write()` and `append()` take JSON, text, a `Blob`, an `ArrayBuffer`, a typed
array, or a `ReadableStream<Uint8Array>`. A reader or a writer never sees half
a `write()`: the new file replaces the old one whole. `write(content, { overwrite: false })`
fails if the file is already there.

## Folders

```ts
await reports.create()                              // with any missing parents
await reports.list()                                // what is directly in it
await reports.list({ recursive: true, depth: 2 })   // and below it
await reports.stat()                                // { modifiedAt }, or null
await reports.clear()                               // empties it, keeps the folder
await reports.delete()                              // removes it and all in it
await reports.space()                               // { capacity, available, used }
```

`list()` gives folders and files together, in path order; tell them apart by
their class:

```ts
import { StorageFile } from "@phreshos/core"

for (const entry of await reports.list()) {
  if (entry instanceof StorageFile) console.log("file", await entry.name())
  else console.log("folder", await entry.name())
}
```

## Copy and move

A file goes to a file, a folder to a folder, each to the exact place given:

```ts
await today.copy(reports.file("backup.json"))
await reports.move(program.data.navigate("archive"))
await today.copy(reports.file("backup.json"), { overwrite: true })
```

Copying and moving never replace what is already there, unless
`overwrite: true`. A folder cannot be copied inside itself. Deleting what does
not exist succeeds.

## Watch for changes

```ts
const stop = new AbortController()

for await (const change of reports.watch({ recursive: true, signal: stop.signal })) {
  console.log(change.event, change.path)   // "change" or "rename", and where
}
```

Aborting the signal ends the loop.

## The files on the machine

`system.storage` starts at the home folder, and reaches absolute paths too:

```ts
const documents = system.storage.navigate("Documents")
const logs = system.storage.navigate("/var/log")

await documents.file("notes.txt").text()
```

Every operation needs the `storage` [permission](/docs/system/permissions)
for its path. A value is a path, optionally limited to some operations:

| Value | Allows |
| --- | --- |
| `Documents/**` | Reading, writing, and deleting under `Documents` |
| `read:Documents/**` | Only reading under `Documents` |
| `read,write:/var/data/report.txt` | Reading and writing one file |

A relative path starts at the home folder, and `~` is not expanded. `/**`
covers everything below a folder, and comes last.

A Node script running as the owner reaches the files directly, with no
permission.

## How long it lasts

`program.data` and `program.cache` belong to the
[Program](/docs/program/programs), not to one run: every Process of it sees the
same files. They stay when the Program is updated or uninstalled, and are
deleted only when it is uninstalled with `purge`. The files on the machine are
the machine's: PhreshOS never deletes them on its own.

## From the terminal

The terminal works on the machine's files directly, as its user. A Program's
own files go with its data:

```sh
phresh uninstall notes --purge   # deletes its files, store, and database
```
