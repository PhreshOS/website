---
title: Opening
description: Open a file, a folder, or a link with the Program its type opens with.

---

A Program can ask the System to open something without knowing which Program
opens it:

```ts
await system.open({ type: "image/png", uri: "file:///Users/me/leaf.png" })
```

## What can be opened

Anything is a media type and a URI:

| Thing | `type` | `uri` |
| --- | --- | --- |
| A link | `x-scheme-handler/https` | `https://example.com` |
| An email address | `x-scheme-handler/mailto` | `mailto:someone@example.com` |
| A file | Its own type, such as `image/png` | `file:///Users/me/leaf.png` |
| A folder | `inode/directory` | `file:///Users/me/Projects` |
| Content you hold | Its type | An [upload](/docs/system/uploads)'s address |

The type is exact: `image/png`, not `image/*`.

## Declare what you open

```ts title="phresh.config.ts"
opens: ["image/*", "application/pdf"]
```

`image/*` stands for every image. To find the Programs that open a type:

```ts
await system.program.list({ opens: "image/png" })
```

## How the System decides

- When the type has a default Program, it opens with it at once.
- Otherwise, when its family has one, such as `image/*` for `image/png`, it
  opens with that.
- Otherwise the owner chooses one of the Programs that open the type, and can
  make it the default.
- When no installed Program opens it, `open()` rejects.

`open()` resolves once a Process is started for it, and rejects when nothing is
chosen. A request ends when the Endpoint that asked stops, or after two minutes.
Asking needs no permission: what opens is always the owner's default or the
owner's choice.

## Receive it

The chosen Program starts a new Process with its default launch, which reads
what it was started to open:

```ts
await context.opened()   // { type, uri }, or null
process.opened           // the same, held by any handle to the Process
```

To keep one Window, the new Process can hand the target to a Process already
running, and end. Reading a `file:` address goes through
[Files](/docs/system/files), and needs its permission.

## Decide for the owner

A Program that replaces the Shell decides requests and defaults through
`system.opening`, with the `all` [permission](/docs/system/permissions):

```ts
system.opening.subscribe("openRequest", async request => {
  await request.choose(request.programs[0], { always: true })   // or request.cancel()
})

await system.opening.defaults()   // { "image/png": Program, "image/*": Program, … }
await system.opening.setDefault("image/png", program)
await system.opening.setDefault("image/*", program)   // only a Program that opens image/*
await system.opening.clearDefault("image/png")

system.opening.subscribe("changeDefault", ({ type, program }) => {})   // program is null once cleared
```

## From the terminal

```sh
phresh system open --type image/png --uri file:///Users/me/leaf.png

phresh opening defaults
phresh opening set-default --type 'image/*' --program preview
phresh opening clear-default --type 'image/*'
phresh opening requests
phresh opening choose --request <identity> --program preview --always
phresh opening cancel --request <identity>
phresh opening wait --event openRequest
```
