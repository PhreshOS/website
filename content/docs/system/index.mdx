title: How it works

The System is PhreshOS itself: the service running on the machine. It keeps
[Programs](/docs/program/programs) running, stores their data, reaches the
files on the machine and the network, and decides what each Program may do.

Code reaches it through `system`, the same way everywhere:

```ts
import { system } from "@phreshos/server"   // in a Server
import { system } from "@phreshos/client"   // in a Client

import { System } from "@phreshos/node"     // in a script on the machine
const system = await System.connect()
```

## What it is

```ts
const about = await system.about()
about.version     // "0.1.108"
about.release     // { name: "Sprout", program: "sprout" }
about.startedAt   // a Date: when the System started
```

`release` names the major version and the Program that looks after it.
`startedAt` is when the System started this time, so how long it has run is
`Date.now() - about.startedAt.getTime()`.

## What decides

What a Program may reach through the System is decided by its
[permissions](/docs/system/permissions), which the owner grants. A Node script
runs as the owner of the machine, so it needs none.

## From the terminal

The `phresh` command reaches the System as its owner, like a Node script:

```sh
phresh system about
phresh system status      # whether its service runs
```
