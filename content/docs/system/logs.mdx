PhreshOS keeps two logs:

- each **Program's log**: every line its Server and Client print;
- the **System log**: what the System itself records, such as a Server that
  stopped unexpectedly.

Both are SQLite tables named `logs`, that you query and follow as records
arrive.

## Query

`query()` runs one read-only statement. Values in a template literal, or in
the list, are passed as values:

```ts
await program.logs.query("SELECT * FROM logs WHERE kind = ? ORDER BY createdAt DESC LIMIT 20", ["error"])

const since = Date.now() - 60_000
await program.logs.query`SELECT * FROM logs WHERE createdAt > ${since}`
```

## Follow

```ts
program.logs.subscribe("log", record => show(record.content))
```

A record arrives once it is stored, so it can already be queried. Following
hears new records only: query for the earlier ones.

## A Program's log

```ts
console.log("started")   // in a Server or a Client
```

| Field | Is |
| --- | --- |
| `createdAt` | When, in Unix milliseconds |
| `process` | The Process that printed it |
| `source` | `"server"` or `"client"` |
| `kind` | `log`, `info`, `warn`, `error`, `debug`, `stdout`, `stderr`, or `exit` |
| `content` | The text |

Every Endpoint that stops is recorded too, as `exit`. Your own Program's log
needs no permission; another's needs the `programs` permission for it.

## The System log

```ts
await system.logs.query("SELECT * FROM logs WHERE level = ?", ["error"])
system.logs.subscribe("log", record => {})
```

| Field | Is |
| --- | --- |
| `createdAt` | When, in Unix milliseconds |
| `level` | `"debug"`, `"info"`, `"warning"`, or `"error"` |
| `source` | The part of the System that recorded it |
| `kind` | The event, such as `unexpectedServerEndpointExit` |
| `content` | For people |
| `data` | The details as JSON, or `null` |

Reading it needs the `logs` [permission](/docs/system/permissions). A Server
that crashes appears in both logs.

## How long they last

Each log keeps its newest 20,000 records. A Program's log is deleted with its
[data](/docs/system/data), when the Program is uninstalled with `purge`.

## From the terminal

```sh
phresh program logs --program notes --statement "select createdAt, kind, content from logs order by createdAt desc limit 20"
phresh system logs --statement "select * from logs where level = 'error'"
```
