---
title: How they fit
description: Which package to use where your code runs, and what they share.
---

Every package reaches the same System, with the same contracts. Pick one by
where your code runs:

| Your code runs | Use | You get |
| --- | --- | --- |
| In a Program's Client | `@phreshos/client` | `context`, `desktop`, `system` |
| In a Program's Server | `@phreshos/server` | `context`, `system` |
| In a script on the machine | `@phreshos/node` | `System.connect()`, `Project` |
| In a terminal | `@phreshos/cli` | The `phresh` command |
| In React components | `@phreshos/react` | Providers and hooks |
| In a React interface | `@phreshos/react-ui` | The PhreshOS components |

`@phreshos/core` holds what they all share: what a Program, a Process, and
every capability are. So a Program means the same thing in a Client, a Server,
and a script, and each concept is explained once, in the chapters before this
one.
