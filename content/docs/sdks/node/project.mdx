---
title: Project
description: Build, run, install, and package a Program project from code.
---

`Project` works with a folder containing a `phresh.config.ts`. It does what
`phresh dev`, `phresh start`, `phresh install`, and `phresh pack` do, from
your own code.

```ts
import { Project, System } from "@phreshos/node"

const project = await Project.open()
const system = await System.connect()

for await (const event of await project.dev(system)) {
  if (event.event === "output") process.stdout.write(event.text)
}
```

## Open a project

```ts
const project = await Project.open()                  // from the current folder
const other = await Project.open("/work/notes")       // a folder or a config file
const defined = Project.define(config, { directory: "/work/notes" })  // from a config object

project.directory       // the project folder
project.config          // its configuration
await project.manifest() // its package.json
```

The configuration is validated when the project opens. Paths in it are
resolved from the project folder, never from where your script runs.

## Run it

`dev()` and `start()` run the Program for as long as you read their events,
like [`runProcess()`](/docs/runtime/processes#run-a-process-for-as-long-as-you-need-it):

| Method | Runs | Like |
| --- | --- | --- |
| `dev(system)` | The development setup: each Endpoint's `devCommand` | `phresh dev` |
| `start(system)` | The production build, as it would be installed | `phresh start` |

```ts
const controller = new AbortController()

for await (const event of await project.start(system, {
  options: { workspace: "personal" },   // launch options for both Endpoints
  signal: controller.signal,            // abort to stop it
})) {
  if (event.event === "started") console.log(event.process.identity)
  if (event.event === "output") process.stdout.write(event.text)
  if (event.event === "exited") console.log(event.exit)
}
```

In development, the Server always runs its `devCommand`. The Client's
`devCommand` receives `PHRESHOS_CLIENT_HOST`, `PHRESHOS_CLIENT_PORT`, and
`PHRESHOS_CLIENT_BASE`: the address to listen on, `127.0.0.1` unless a `devUrl`
names another, its port, and the path to serve under. If that command ends,
the development Process ends too. A Client `devUrl`
uses a server that is already running instead.

`start()` runs the `buildCommand` first.

## Install it

```ts
for await (const chunk of await project.install(system, { launch: true })) {
  process.stdout.write(chunk.text)
}
```

`install()` builds the project, replaces any Program with the same identity
by the project's definition, and installs it. It takes the same options as
[`program.install()`](/docs/runtime/programs#install-and-uninstall): `launch` and
`purge`.

## Package it

```ts
const packed = await project.pack()
// { archive, archivePath, declarationPath, checksumPath, digest }
```

`pack()` builds the project and writes a release: a zip with each production
Endpoint, `program.json`, and the icon and agent document if declared, plus a
SHA-256 checksum.

The version comes from `config.version`, then `package.json`, then `0.0.0`.

## Build or read the definition

```ts
await project.build()                  // run buildCommand
project.productionDefinition()         // the installed form
project.developmentDefinition()        // the phresh dev form
```

Both definitions are Core `ProgramDefinition` values, the same kind
[`system.program.create()`](/docs/runtime/programs#create-a-program-from-a-definition)
accepts.

## Reference

| Member | Result |
| --- | --- |
| `Project.open(source?)`, `Project.define(config, { directory }?)` | A Project |
| `directory`, `config`, `manifest()` | The project folder, configuration, and `package.json` |
| `dev(system, { options, signal }?)` | Run the development setup |
| `start(system, { options, signal }?)` | Run the production build |
| `install(system, { launch, purge }?)` | Build and install |
| `pack()` | Build and write a release |
| `build()`, `productionDefinition()`, `developmentDefinition()` | Build, or read the resolved definitions |
