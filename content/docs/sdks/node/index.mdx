`@phreshos/node` is for code that runs outside any Program: scripts,
automation, agents, build tools, and the `phresh` command itself. It does two
things:

- **`System.connect()`** connects to the System on this machine as its owner;
- **`Project`** builds, runs, installs, and packages a Program project. See
  [Project](/docs/sdks/node/project).

## Connect to the System

```ts
import { System } from "@phreshos/node"

const system = await System.connect()

const programs = await system.program.list()
const notes = await system.program.find("notes")
await notes?.createProcess({ client: true })

await system.disconnect()
```

`system` is the same [System](/docs/system) as inside a Program, with the whole
API available.

For a running Client, `process.client.memory` reads and changes the same
run-scoped values that its browser views use. See [Client memory](/docs/runtime/endpoints#client-memory).

`System.connect()` finds the System through its home folder: `PHRESHOS_HOME`
if set, otherwise `~/.phreshos`, the same as the `phresh` command. Pass
another folder to connect to a different System:

```ts
const system = await System.connect("/srv/phreshos")
```

The connection is a local socket in that folder (a named pipe on Windows).
It is not a browser [Connection](/docs/system/security/authentication) and needs no
Session.

## Connected as the owner

Only someone who can open that socket, the user running PhreshOS, can
connect. So a Node connection is trusted as the owner:

- it sees every Program, Process, and Service;
- it is not limited by Program permissions;
- it can assign permissions and decide pending requests through
  [`program.permissions` and `system.permissions`](/docs/system/security/permissions).

It has no `context`, because it is not running inside a Program. For the same
reason, it cannot request permissions.

## What runs in Node

`system.shell()` and `system.storage` run directly in the Node process, with
the same API. Everything else, such as Programs, Processes, Services,
Appearance, uploads, network, and logs, goes through the System.

## Disconnect

`disconnect()` closes the connection and ends everything opened through it:
subscriptions, pending calls, shell commands, and attached runs. Later calls
on that `system` reject.

Disconnecting affects only this script. The System keeps running, and
Programs and their state are not changed.

## Locate the System without connecting

```ts
import { gatewayAddress, resolveHome } from "@phreshos/node"

const home = resolveHome()          // the System home folder
const socket = gatewayAddress(home) // the socket or pipe inside it
```
