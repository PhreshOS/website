`Table` shows records in columns. Each column and row has an `id`, and each
cell can hold any content.

```tsx
<Table aria-label="Processes">
  <Table.Header>
    <Table.Column id="name" rowHeader>Name</Table.Column>
    <Table.Column id="state">State</Table.Column>
  </Table.Header>
  <Table.Body>
    <Table.Row id="notes">
      <Table.Cell>Notes</Table.Cell>
      <Table.Cell>Running</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>
```

Mark the column that names each row with `rowHeader`, so screen readers can
announce rows by it.

## Rows from data

```tsx
<Table.Body items={processes}>
  {process => (
    <Table.Row id={process.id}>
      <Table.Cell>{process.name}</Table.Cell>
      <Table.Cell>{process.state}</Table.Cell>
    </Table.Row>
  )}
</Table.Body>
```

When the render function uses other state, pass it in `dependencies` so rows
update. `renderEmptyState` shows content when there are no rows.

## Selection and actions

Rows are not selectable by default. Selection works as in every collection:

```tsx
<Table aria-label="Processes" selectionMode="multiple" value={selected} onChange={setSelected}>
  …
</Table>
```

`onAction(id)` opens a row, separately from selecting it. A row is disabled
with `disabled` on it.

## Sorting

Mark columns `sortable`. The Table reports what the person asked for; you sort
the data and pass the result back:

```tsx
const [sort, setSort] = useState({ column: "name", direction: "ascending" })

<Table aria-label="Processes" sort={sort} onSortChange={setSort}>
  <Table.Header>
    <Table.Column id="name" rowHeader sortable>Name</Table.Column>
    <Table.Column id="state" sortable>State</Table.Column>
  </Table.Header>
  <Table.Body items={sortBy(processes, sort)}>…</Table.Body>
</Table>
```

An arrow appears on the column the table is sorted by.

## Drag and drop

Rows can be dragged out and things dropped onto them, with `useDragAndDrop`.
Drags are the browser's own: they reach other frames and other applications,
and files dragged in from the machine arrive as drop items of kind `file` or
`directory`.

```tsx
const { dragAndDropHooks } = useDragAndDrop({
  getItems: ids => [...ids].map(id => ({ "text/plain": String(id) })),
  onItemDrop: event => move(event.items, event.target.key)
})

<Table aria-label="Files" dragAndDropHooks={dragAndDropHooks}>…</Table>
```

A row a drag would drop onto shows as selected, and a Table that takes the drop
as a whole is outlined as focus is.

## Look

Selected rows show the `subtle` level of the Table's `color`, `primary` by default,
under the same veil as hover.
The Table has no background or scrolling of its own; put it in a Surface, a
Panel, or a horizontal ScrollArea.
