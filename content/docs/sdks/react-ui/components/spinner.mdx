`Spinner` shows that something is in progress, where a
[`ProgressBar`](/docs/sdks/react-ui/components/progress-bar) would not fit.

```tsx
<Spinner label="Loading workspace" />
```

`label` names it for screen readers; it shows no text.

## Next to visible text

When text beside it already says what is happening, mark it `decorative`, so it
is not announced twice:

```tsx
<span role="status">
  <Spinner decorative /> Connecting to the System
</span>
```

A Spinner needs either a `label` or `decorative`.

It is a comet in `primary`: a head leading a tail that fades behind it. Each
turn quickens and slows like the interface's own motion, and the tail follows
the head a moment behind, so it stretches as the comet speeds up and gathers
into the head as it slows, stretching nearly half way round. A turn lasts
twelve Appearance transactions. With animations off it rests as its shape.

A Button that is `pending` shows it in place of its content, and
[Loading](/docs/sdks/react-ui/components/loading) shows it while it waits.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `label` | — | Its name for screen readers |
| `decorative` | `false` | Hide it from screen readers |
| `color` | `"primary"` | The comet |
| `size` | `"medium"` | Its diameter |
