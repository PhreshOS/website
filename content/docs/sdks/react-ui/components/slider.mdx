`Slider` picks a number within a range, such as a volume or a scale.

```tsx
const [volume, setVolume] = useState(40)

<Slider label="Volume" value={volume} onChange={setVolume} />
```

## Range and steps

```tsx
<Slider label="Desktop scale" minValue={0.5} maxValue={2} step={0.1} value={scale} onChange={setScale} />
```

## Save when the drag ends

`onChange` fires continuously while dragging; `onChangeEnd` fires once when
released. Update the screen in `onChange`, and save in `onChangeEnd`:

```tsx
<Slider label="Scale" value={scale} onChange={setScale} onChangeEnd={saveScale} />
```

## Format and orientation

```tsx
<Slider
  aria-label="Level"
  orientation="vertical"
  maxValue={1}
  step={0.01}
  formatOptions={{ style: "percent" }}
  style={{ height: 180 }}
/>
```

The track is recessed and fills with `primary` up to the thumb.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `value`, `defaultValue`, `onChange` | — | Its value |
| `onChangeEnd` | — | Called when a drag ends |
| `minValue`, `maxValue`, `step` | `0`, `100`, `1` | Its range |
| `orientation` | `"horizontal"` | Its direction |
| `formatOptions` | — | How the value is shown, as `Intl.NumberFormat` options |
| `label`, `description` | — | Its text |
| `name`, `form` | — | Form submission |
| `color` | `"primary"` | Its fill |
| `size`, `material`, `disabled` | — | Its size, material, and state |
