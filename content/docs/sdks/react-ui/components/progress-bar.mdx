`ProgressBar` shows long work. It only reports; people cannot change it. For a
short wait of a few seconds, use a [`Spinner`](/docs/sdks/react-ui/components/spinner).

```tsx
<ProgressBar label="Uploading archive" value={64} />
```

## Measured progress

When the work's progress is known and can be followed, such as files copied out
of a known number, give its `value`. `value` sits between `minValue` and `maxValue`, `0` and `100` by default. The
bar fills with `primary` in a recessed track.

```tsx
<ProgressBar label="Files copied" value={3} maxValue={8} valueLabel="3 of 8" />
```

The shown value is a percentage by default. `valueLabel` replaces it with your
own text, and `formatOptions` changes its number format.

## Unknown progress

When long work is running and nothing tells when it ends, such as installing a
Program, use `indeterminate`:

```tsx
<ProgressBar label="Installing Terminal" indeterminate />
```

It moves continuously, and stays still when animations are off.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `value`, `minValue`, `maxValue` | `0`, `0`, `100` | Progress |
| `indeterminate` | `false` | Running, but unmeasured |
| `label` | — | The visible label; or use `aria-label` |
| `valueLabel`, `formatOptions` | A percentage | The shown value |
| `color` | `"primary"` | The fill |
| `size`, `material` | `"medium"`, `"basic"` | Its size and track material |
