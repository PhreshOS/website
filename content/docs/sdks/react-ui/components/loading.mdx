`Loading` is a [Readiness](/docs/sdks/react-ui/components/readiness) boundary
with the System's own loading drawn in place of the interface that waits, so
a Program does not design its own. Wrap the interface that waits, and declare what it needs with
`useRequirement`. The detail of a requirement is its message:

```tsx
import { Loading, useRequirement } from "@phreshos/react-ui"

<Loading>
  <Settings />
</Loading>

// inside Settings:
useRequirement(connected, "Connecting…")
useRequirement(settingsLoaded)
```

It shows a Spinner with the message of the first requirement that is waiting.
A requirement without a string detail is waited for, but not shown. There is
no default message.

While it waits, the interface is hidden, not covered: it keeps its place and
size, and nothing is painted behind the Spinner, so the Surface it sits on,
such as the Window's, shows through. The loading fills the nearest positioned
ancestor. It appears at once; when everything is ready it fades out as a
[change in place](/docs/sdks/react-ui/motion), and the interface appears whole at once. It cannot
fade in, because the interface stays a direct part of the layout around it,
with no box of its own that could fade. When a requirement stops being ready,
the loading appears again.

`className` and `style` go to the layer that shows the loading, such as to
move where it stands.

## Steps

With `steps`, every requirement that has a message gets its own line, with a
Spinner while it waits and a check when it is ready. Use it when several
things load at once and each is worth seeing.

## Delay

`delay` keeps the interface held and the loading shown for that many
milliseconds after its requirements are ready, as with
[Readiness](/docs/sdks/react-ui/components/readiness#delay). Use it for work the
requirements cannot see, such as an animation that runs after the content
loads.

## Reference

| Prop | Does |
| --- | --- |
| `children` | The interface that waits |
| `className`, `style` | The layer that shows the loading |
| `steps` | Lists every step instead of one message |
| `delay` | Milliseconds to stay held after ready, `0` by default |

For a loading state of your own, use
[Readiness](/docs/sdks/react-ui/components/readiness) with `status`.
