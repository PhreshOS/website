`ListBox` shows a list people can choose from without opening anything.

```tsx
<ListBox aria-label="Tool" value={tool} onChange={setTool}>
  <ListBox.Item id="editor">Editor</ListBox.Item>
  <ListBox.Item id="terminal">Terminal</ListBox.Item>
  <ListBox.Item id="archive" disabled>Archive</ListBox.Item>
</ListBox>
```

## One or several

A ListBox selects one item by default; its value is an `id` or `null`. With
`selectionMode="multiple"`, its value is a list of `id`s, or `"all"`:

```tsx
const [tools, setTools] = useState<readonly string[] | "all">(["editor"])

<ListBox aria-label="Tools" selectionMode="multiple" value={tools} onChange={setTools}>
  …
</ListBox>
```

## Groups and data

`ListBox.Section` with a `ListBox.Header` groups items. For data, map items
yourself, or pass `items` with a render function.

Use [`Tree`](/docs/sdks/react-ui/components/tree) when items have children.

## Look

A selected item shows the `subtle` level of its `color`, `primary` by default,
under the same veil as hover, so a selection is never less visible than hovering.

ListBox has no background or scrolling of its own; put it in a Surface or a
ScrollArea when needed.

## Parts

| Part | Props |
| --- | --- |
| `ListBox` | `selectionMode`, `value`, `defaultValue`, `onChange`, `items`, `aria-label`, `focusOnHover`, `focusWrap`, `selectOnPressUp`, `color` (`"primary"`), `size`, `radius` |
| `ListBox.Item` | `id`, `disabled`, `color` |
| `ListBox.Section` | `id` |
| `ListBox.Header` | Its text |
