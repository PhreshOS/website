`Checkbox` is a choice that is on or off. Its value is a boolean.

```tsx
<Checkbox label="Include finished Processes" checked={include} onChange={setInclude} />
```

Use `checked` to own the value, or `defaultChecked` to let the Checkbox keep
it.

## Some selected

`indeterminate` shows a mixed state, for a "select all" box when only some
items are selected. The value stays a boolean.

```tsx
<Checkbox
  label="Select all"
  checked={all}
  indeterminate={some && !all}
  onChange={selectAll}
/>
```

## Look

Unchecked, the box is recessed. Checked, it rises in `primary`. Change it
with `color`, `size`, and `material`.

Use [`Switch`](/docs/sdks/react-ui/components/switch) for a setting that takes
effect immediately. Use Checkbox for a choice that is applied later, such as
in a form.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `checked`, `defaultChecked`, `onChange` | — | Its value |
| `indeterminate` | `false` | Show a mixed state |
| `label`, `description`, `errorMessage` | — | Its text |
| `invalid`, `required`, `readOnly`, `disabled` | `false` | Its state |
| `color` | `"primary"` | Its checked color |
| `size`, `radius`, `material` | — | Its look |
