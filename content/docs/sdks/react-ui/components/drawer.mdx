`Drawer` holds what a narrow layout gives up to its content and keeps it one
press away. It opens over the content from the start side. An
[`AppLayout`](/docs/sdks/react-ui/components/app-layout) already puts its
sidebar in one when it is narrow; use `Drawer` directly for any other layout:

```tsx
const [open, setOpen] = useState(false)

<Drawer open={open} onClose={() => setOpen(false)} title="Files">
  <nav aria-label="Places">…</nav>
</Drawer>
```

The layout decides when it is narrow and keeps whether the Drawer is open. A
choice inside the Drawer usually closes it too. What it holds scrolls inside it,
while the Drawer itself stays in place.

It is placed in its nearest positioned container, so give the element it covers
`position: relative`. A press outside it or Escape calls `onClose`. Escape stops
at the Drawer, so a menu or dialog that holds it stays open.

It is a frosted Surface with the `full` material. It slides in and back out along
the same path, timed as a [change in place](/docs/sdks/react-ui/motion), and simply shows and goes
when animations are off. Only its position moves, so it keeps showing what is
behind it through its material.

## Props

| Prop | Default | Sets |
| --- | --- | --- |
| `open` | — | Whether it is shown |
| `onClose` | — | Called for a press outside or Escape |
| `title` | — | What it shows at its top, such as the program's name |
| `aria-label` | — | Its name for screen readers |
