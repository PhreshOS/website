`Tooltip` shows a short text when someone points at or focuses its trigger,
typically to explain an icon.

```tsx
<Tooltip>
  <Tooltip.Trigger aria-label="Information">
    <InfoIcon />
  </Tooltip.Trigger>
  <Tooltip.Content>Visible only to this Program</Tooltip.Content>
</Tooltip>
```

The trigger still needs its own name, such as `aria-label`: a tooltip does not
replace it.

`Tooltip.Trigger` is a Button. A Button you already have is described the same
way when it stands inside the `Tooltip`, even one wrapped in its own
[context menu](/docs/sdks/react-ui/components/context-menu):

```tsx
<Tooltip>
  <ContextMenu>
    <ContextMenu.Trigger><Button aria-label="Notes"><NotesIcon /></Button></ContextMenu.Trigger>
    <ContextMenu.Content>…</ContextMenu.Content>
  </ContextMenu>
  <Tooltip.Content>Notes</Tooltip.Content>
</Tooltip>
```

Like other overlays, `Tooltip.Content` takes a `portalContainer`: the element
it is drawn in, such as one whose scale it should share.

It opens once the pointer has rested on the trigger for four changes in
place, or at once on keyboard focus; `delay` sets another wait.

Keep tooltips to a few words, and never put anything required or clickable in
them. Use [`Popover`](/docs/sdks/react-ui/components/popover) for that.

## Parts

| Part | Props |
| --- | --- |
| `Tooltip` | `open`, `defaultOpen`, `onOpenChange`, `delay`, `closeDelay`, `closeOnPress`, `disabled` |
| `Tooltip.Trigger` | Button props |
| `Tooltip.Content` | `placement` (`"top"`), `portalContainer`, Surface props |
