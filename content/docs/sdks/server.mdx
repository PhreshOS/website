```ts title="server/main.ts"
import { context, system } from "@phreshos/server"

context.answer("notes.list", () => loadNotes())
```

`context` and `system` are explained in the chapters before: see
[Context](/docs/program/context) and [The System](/docs/system).

## Only in a Server

- `context.answer()`: only a Server answers questions;
- `context.client`: the Client of the same Process.

There is no `desktop`: a Server is not shown on a Desktop. How it runs is in
[Execution](/docs/system/execution).
