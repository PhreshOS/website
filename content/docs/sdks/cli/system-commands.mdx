---
title: System commands
description: Install, update, run, and remove PhreshOS itself.
---

`phresh system` manages PhreshOS on this machine: installing it, running its
service, and removing it.

| Command | Does |
| --- | --- |
| `phresh system install` | Installs or updates PhreshOS and starts it |
| `phresh system status` | Shows the version, whether it runs, and the Desktop address |
| `phresh system version` | Shows the installed version |
| `phresh system start`, `stop` | Starts or stops the service now |
| `phresh system enable`, `disable` | Turns starting at login on or off |
| `phresh system uninstall` | Removes PhreshOS and its service |
| `phresh system about` | Shows the System's name, version, and release |
| `phresh system icon` | Writes the System's icon to a PNG file |
| `phresh system open` | Opens something with its type's Program; see [Opening](/docs/system/opening) |
| `phresh system logs` | Queries the System log |

```sh
phresh system install
phresh system status
```

`install --purge` and `uninstall --purge` also delete all of PhreshOS's data.
See [Installation](/docs/installation) for what each command does on each
operating system.

## At a glance

`phresh fetch` shows the running System beside its logo: its version and
release, how long it has run, the Desktop address, the installed Programs and those that start with
the System, the running Processes and their Windows, the connected Desktops and
Sessions, the wallpaper, and the Appearance colors of both themes.

```sh
phresh fetch
phresh fetch --json
```

## Query the System log

```sh
phresh system logs --statement 'select * from logs where level = ? order by createdAt desc limit 50' --values '["error"]'
```

The statement is read-only SQL over the System's `logs` table. See
[Logs](/docs/system/logs).

Programs, Processes, and Windows are managed with the
[runtime commands](/docs/sdks/cli/runtime-commands), not under `system`.
